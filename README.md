# スイッチLite

League of Legends のアカウントを、ワンクリックで切り替える Windows 用ツールです。

## ダウンロード

右の **Releases** から、最新の `SwitchLite_v◯.◯.◯.zip` をダウンロードしてください。
zip の中身は次の3つです。

| ファイル | 内容 |
|---|---|
| `スイッチLite.exe` | 本体 |
| `設定フォルダを開く.bat` | 設定フォルダを開きます（ランク表示用の API キーを入れるとき） |
| `はじめに.txt` | 使い方 |

## できること

- 登録したアカウントへ、ワンクリックで切り替え（2つまで）
- 各アカウントのランク表示（Riot API キーを入れた場合）
- 自動承諾（マッチが見つかったら自動で承諾）
- フレンドから隠す（フレンドからオフラインに見せる）

## 動く環境

- Windows 10 / 11
- Riot Client（League of Legends）がインストールされていること
- 起動時に **注文番号**（GitHub から入手した人はニックネーム）の入力が必要です

## 使い方

1. zip を好きな場所に展開して、`スイッチLite.exe` を起動します（管理者として起動します）。
2. はじめて起動したときに、注文番号を入力します。GitHub からダウンロードした人は、注文番号の代わりに **ニックネームなど（ほかの人と被らない名前）** を入力してください（サポートのときに使います）。
3. タスクトレイ（画面右下）のアイコンを押すと、アカウントの一覧が出ます。
4. 「＋ アカウントを追加」から、Riot のログイン ID とパスワードを登録します。
5. 一覧のアカウントを押すと、そのアカウントに切り替わります。

### ランクを表示したいとき（任意）

1. `設定フォルダを開く.bat` をダブルクリックします。
2. メモ帳で `.env` が開くので、`RIOT_API_KEY=` の後ろに、自分の Riot API キーを貼って保存します。
   キーは [Riot Developer Portal](https://developer.riotgames.com) で取得できます。

## うまく動かないとき

- 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（署名していないアプリのため表示されます）。
- ログインしたパスワードは、この PC の中だけに暗号化して保存されます。
